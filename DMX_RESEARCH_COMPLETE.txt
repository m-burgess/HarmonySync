TECHNICAL HIGHLIGHTS
===============================================================================

Architecture:
  React UI → Tauri IPC → Rust DMX Engine → USB → DMX Interface → Fixtures

Features:
  - Scene storage and recall (SQLite)
  - Smooth transitions with fading (1-10 seconds)
  - 512 channels per universe
  - 45 Hz refresh rate
  - Fixture library (10-15 common types)
  - Phillips Hue integration via HTTP API

Hardware Support:
  - ENTTEC DMX USB PRO (recommended, $200)
  - Generic USB-DMX512 interfaces ($25-50)
  - Art-Net/sACN (network DMX, Phase 3)
