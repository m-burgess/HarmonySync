# HarmonySync Example Scripts

This directory contains example scripts demonstrating the HarmonySync Scripting API.

## Example Scripts

1. **display-black-screen.js** - Simple example showing black screen
2. **toggle-audience.js** - Toggle audience window visibility
3. **midi-sequence.js** - Send a sequence of MIDI notes
4. **countdown-timer.js** - Display countdown timer on slides
5. **auto-lower-thirds.js** - Auto-cycle through lower thirds messages
6. **window-manager.js** - Demonstrate window management

## Usage

Import these scripts into the Script Editor to get started with the HarmonySync Scripting API.

## API Documentation

See `SCRIPTING_API.md` in the root directory for complete API documentation.
