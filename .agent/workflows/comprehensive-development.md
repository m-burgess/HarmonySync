# Comprehensive Development Workflow

This workflow orchestrates all available specialized agents to deliver high-quality features.

## Phase 1: Product & Vision 🎯
1. **Product Owner** (`product-owner`)
   - Define vision, scope, and user value.
   - Create acceptance criteria and MVVM guidelines.
   - Ensure alignment with commercial goals.

2. **UX Designer** (`ux-designer`)
   - Create/review user flows and wireframes.
   - Ensure accessibility and usability.
   - Design responsive and intuitive interfaces.

## Phase 2: Architecture & Design 🏗️
3. **Integration Architect** (`integration-architect`)
   - Design API contracts and shared data models.
   - Plan cross-platform communication (IPC/WebSockets).
   - define deployment and integration strategies.

4. **OOP Design Expert** (`oop-design-expert`)
   - Model domain entities and relationships.
   - Apply SOLID/GRASP principles.
   - Design class structures and interfaces.

5. **Cross-Platform Systems Expert** (`cross-platform-systems-expert`)
   - Address OS-specific requirements (Windows, macOS, Linux).
   - Configure FFmpeg, MIDI, and display systems.
   - Ensure consistent behavior across platforms.

## Phase 3: Planning & Coordination 📋
6. **Project Manager** (`project-manager`)
   - Synthesize inputs from all experts.
   - Create detailed implementation plans (Backend, Frontend, QA).
   - Manage dependencies and risks.

7. **GitHub Workflow Expert** (`github-workflow-expert`)
   - Review/design necessary CI/CD changes.
   - Ensure workflow efficiency and security.
   - Troubleshoot pipeline configurations.

## Phase 4: Backend Implementation 🔧
8. **Backend Expert** (`backend-expert`)
   - Implement Node.js/GoLang backend logic.
   - Build secure APIs and database integrations.
   - Optimize performance and resource usage.

9. **Node.js Expert** (`node-js-expert`)
   - Refine Node.js specific implementations.
   - Optimize Electron/Node.js interop.
   - Assist with package management and tooling.

10. **TypeScript Expert** (`typescript-expert`)
    - Ensure type safety and best practices in backend code.
    - Refactor complex type logic.
    - Verify strict null checks and error handling.

## Phase 5: Frontend Implementation 🎨
11. **Frontend Expert** (`frontend-expert`)
    - Implement React components and MVVM patterns.
    - Apply TailwindCSS styling.
    - Connect frontend to backend services.

12. **Media Systems Engineer** (`media-systems-engineer`)
    - Implement audio/video processing logic.
    - Configure DMX/MIDI controls.
    - Optimize media playback performance.

## Phase 6: Quality Assurance 🧪
13. **TDD Testing Expert** (`tdd-testing-expert`)
    - Guide test-first development.
    - Provide templates for unit/integration tests.
    - Ensure red-green-refactor cycle.

14. **QA Testing Expert** (`qa-testing-expert`)
    - Execute comprehensive test plans.
    - Perform regression and E2E testing.
    - Verify code coverage and reliability.

## Phase 7: Documentation & Finalization 📚
15. **README Skill** (`readme`)
    - Update project documentation.
    - Verify documentation completeness.
    - Ensure consistency with implemented features.

## Execution Steps

1.  **Product Owner** defines the feature.
2.  **UX Designer** & **Integration Architect** design the solution.
3.  **Project Manager** creates the plan.
4.  **TDD Testing Expert** provides test guidance.
5.  **Backend** & **Frontend** teams implement (iteratively).
6.  **QA Testing Expert** verifies everything.
7.  **Project Manager** validates against original plan.
