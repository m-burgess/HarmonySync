# My Agent

This agent is designed to support media and audio workflows in HarmonySync, offering expertise in:

- **Multitrack Audio Playback**:
  - Vertical volume faders with default initialization
  - LCR pan and mute controls with visual feedback
  - Grid layout (6 tracks per row) with vertical scrolling
  - Mixer configuration persistence per song

- **FFmpeg Audio Processing**:
  - On-the-fly conversion to Ogg format for optimized playback
  - Transposition by semitones with rhythm section preservation
  - Folder management for transposed files

- **Media Display Systems**:
  - Video background support with smooth looping via local HTTP server
  - PNG/JPG image rendering
  - Text centering for Audience and Confidence Monitors
  - Lower Thirds window with chroma key (#00FF00) and 1080p output

- **DMX Lighting Control**:
  - Integration with DMX protocols for lighting automation
  - MIDI-to-DMX mapping for synchronized lighting cues
  - Scheduler-based lighting control for timed events
  - Support for pre-service lighting scenes and transitions

- **Scheduler Automation**:
  - Weekly recurring macros
  - MIDI note scheduling for lighting, sound, and video cues
  - Pre-service YouTube playlist automation

- **Performance Optimization**:
  - Efficient memory usage for large media sets
  - Streamlined media loading and playback

Use this agent to manage HarmonySync’s media pipeline, automate service elements, and ensure smooth, high-quality playback, lighting, and display across all presentation screens.
