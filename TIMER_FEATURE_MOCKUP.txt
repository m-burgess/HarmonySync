## States Visualization
```
╔═══════════════════════════════════════════════════════════╗
║ TIMER STATES                                              ║
╠═══════════════════════════════════════════════════════════╣
║                                                            ║
║  ● STOPPED (Gray)                                         ║
║    - Timer at initial duration                            ║
║    - Shows [▶ Start] button                              ║
║    - Can edit or delete                                   ║
║                                                            ║
║  ● RUNNING (Green)                                        ║
║    - Countdown active                                     ║
║    - Updates every second                                 ║
║    - Shows [⏸ Pause] button                              ║
║    - Badge visible on activity bar                        ║
║                                                            ║
║  ● PAUSED (Yellow)                                        ║
║    - Countdown stopped at current time                    ║
║    - Shows [▶ Start] button to resume                    ║
║    - Can stop or reset                                    ║
║                                                            ║
╚═══════════════════════════════════════════════════════════╝
```

## Feature Highlights
```
✓ Multiple timers supported simultaneously
✓ Countdown displayed in hh:mm or mm:ss format
✓ Real-time updates (1 second intervals)
✓ Persistent storage (survives app restart)
✓ Target specific displays
✓ Visual status indicators (color-coded)
✓ Badge shows running timer count
✓ Easy-to-use controls (start, pause, stop, reset)
✓ Create, edit, delete timers
✓ Duration input in hours:minutes format
```
